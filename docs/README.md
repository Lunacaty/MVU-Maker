## 核心概念速查（一句话版）

- **角色卡** = JSON（`chara_card_v2`）或 PNG（JSON 藏在 tEXt 的 `chara` 字段）+ 头像
- **世界书** = 内嵌于角色卡的 `character_book`，条目有蓝灯（恒定）/绿灯（关键词）两种激活策略
- **正则脚本** = 对消息做字符串替换，分"仅格式提示词"（改发给 AI 的内容）和"仅格式显示"（改玩家看到的内容）两个方向
- **酒馆助手脚本** = 运行在 iframe 里的 JS，能做后台逻辑、前端界面、事件监听、直接读写变量
- **MVU** = 酒馆助手的变量框架：`stat_data` 变量 + 让 AI 输出 `<UpdateVariable>` 命令 + zod 校验 + 事件钩子
- **`{{format_message_variable::stat_data}}`** = 把变量变成 YAML 塞进 AI 上下文 / 状态栏显示的宏

| 绿灯 | Selective | 关键词触发激活的条目 |
| 正则脚本 | Regex Script | 消息替换规则 |
| 酒馆助手 | Tavern-Helper | 第三方扩展，渲染 HTML、跑脚本 |
| MVU | Magical Variable Update | 酒馆助手的变量框架 |
| 楼层 | Message | 一条聊天消息 |
