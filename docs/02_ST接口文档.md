## 1. 接口访问方式

三种访问途径，指向同一批函数：

| 途径 | 场景 | 说明 |
|------|------|------|
| **裸函数** | 酒馆助手 iframe 内（脚本/界面） | `getVariables(...)`、`eventOn(...)` —— 已在 iframe 全局 |
| **`TavernHelper.*`** | 主界面/插件 | `window.TavernHelper.getVariables(...)` |
| **`SillyTavern.*`** | 酒馆原生 | 底层接口，优先用 TavernHelper 上层接口 |

> 在酒馆助手 iframe 中**裸函数与 `TavernHelper.*` 等价**，`predefine.js` 会把
> `_eventOn → eventOn` 等下划线前缀函数解绑到 iframe 全局。

**通用类型 `VariableOption`**（决定操作哪一级变量）：

```ts
type VariableOption =
  | { type: 'chat' | 'preset' | 'global' }
  | { type: 'character' }                            // 当前角色卡
  | { type: 'message'; message_id?: number | 'latest' }  // 楼层；负数=深度，-1 最新
  | { type: 'script'; script_id?: string }            // 脚本变量，不持久化
  | { type: 'extension'; extension_id: string };
```

## 2. 变量 API（variables）

变量分 5 层存储，读取链见下表：

| 类型 | 存储 | 持久化 |
|------|------|--------|
| `global` | 全局设置文件 | ✅ |
| `character` | 角色卡数据 | ✅ |
| `chat` | 聊天元数据 | ✅ |
| `message` | 单个楼层 | ✅ |
| `script` | Pinia 内存 | ❌ 不持久化 |

### `getVariables(option)` → 变量表

```js
getVariables({ type: 'chat' });                      // 聊天变量
getVariables({ type: 'message', message_id: -1 });   // 最新楼层变量
getVariables({ type: 'message', message_id: -2 });   // 倒数第二楼
getVariables({ type: 'message', message_id: 5 });    // 第5楼
getVariables({ type: 'script' });                    // 本脚本变量
```

### `replaceVariables(variables, option)`

完全替换变量表。**底层的一切**：其余修改函数都是"先 get 再改再 replace"。

```js
let variables = getVariables({ type: 'chat' });
_.unset(variables, '神乐光.好感度');
replaceVariables(variables, { type: 'chat' });
```

### `updateVariablesWith(updater, option)` → 更新后的变量表

```js
updateVariablesWith(vars => _.update(vars, '爱城华恋.好感度', v => (v ? v * 2 : 0)), { type: 'chat' });
// 也支持 async updater
```

### `insertOrAssignVariables(variables, option)` / `insertVariables(variables, option)`

- `insertOrAssignVariables`：存在则改，不存在则加
- `insertVariables`：仅不存在时加

### `deleteVariable(path, option)` → `{ variables, delete_occurred }`

```js
deleteVariable("爱城华恋.好感度", { type: 'chat' });
```

### `registerVariableSchema(schema, option)`

仅为酒馆"变量管理器"UI 提供校验结构，对代码无影响。

```js
registerVariableSchema(z.object({
  stat_data: z.object({ 好感度: z.number() }),
}), { type: 'message' });
```

## 3. 消息楼层 API（chat_message）

### 消息结构

```ts
type ChatMessage = {
  message_id: number;
  name: string;
  role: 'system' | 'assistant' | 'user';
  is_hidden: boolean;
  message: string;          // 消息正文
  data: Record<string, any>; // 楼层变量就存在 data 里
  extra: Record<string, any>;
};
type ChatMessageSwiped = ChatMessage & {
  swipe_id: number;
  swipes: string[];
  swipes_data: Record<string, any>[];
  swipes_info: Record<string, any>[];
};
```

### `getChatMessages(range, option)`

- `range`：楼层号或范围，如 `0`、`'0-{{lastMessageId}}'`、`-1`（最新）、`-2`
- `option`：`{ role, hide_state, include_swipes }`
- `include_swipes: false`（默认）→ `ChatMessage[]`；`true` → `ChatMessageSwiped[]`

```js
getChatMessages(-1)[0].message;                    // 最新 AI 消息正文
getChatMessages('0-{{lastMessageId}}');            // 全部消息
```

### `setChatMessages(messages, { refresh })` → Promise

修改已有楼层。`refresh`: `'none' | 'affected' | 'all'`。

```js
await setChatMessages([{ message_id: 10, message: '新消息' }]);
await setChatMessages([{ message_id: 0, swipe_id: 2 }]);          // 切换开局
await setChatMessages([{ message_id: 0, data: chat_message.data }], { refresh: 'none' }); // 补楼层变量
```

### `createChatMessages(messages, { insert_before, refresh })` → Promise

```js
await createChatMessages([{ role: 'user', message: '你好' }]);
await createChatMessages([{ role: 'assistant', message, data }]);  // 带楼层变量创建
```

### `deleteChatMessages(message_ids, { refresh })` → Promise

```js
await deleteChatMessages([10, 15, -2, getLastMessageId()]);
```

### `rotateChatMessages(begin, middle, end, { refresh })` → Promise

把 `[begin,middle)` 与 `[middle,end)` 互换。

```js
await rotateChatMessages(1, getLastMessageId() - 2, getLastMessageId() + 1); // 最后3楼移到第1楼前
```

## 4. 世界书 API（worldbook）

### 条目结构

```ts
type WorldbookEntry = {
  uid: number;             // 世界书内部相对 id，不可跨书使用
  name: string;
  enabled: boolean;
  strategy: {
    type: 'constant' | 'selective' | 'vectorized';
    keys: (string | RegExp)[];
    keys_secondary: { logic: 'and_any'|'and_all'|'not_all'|'not_any'; keys: [] };
    scan_depth: 'same_as_global' | number;
  };
  position: {
    type: 'before_character_definition'|'after_character_definition'
        |'before_example_messages'|'after_example_messages'
        |'before_author_note'|'after_author_note'|'at_depth'|'outlet';
    role: 'system'|'assistant'|'user';
    depth: number;
    order: number;
  };
  content: string;
  probability: number;
  recursion: { prevent_incoming: boolean; prevent_outgoing: boolean; delay_until: null|number };
  effect: { sticky: null|number; cooldown: null|number; delay: null|number };
  extra?: Record<string, any>;
};
```

### 绑定管理

| 函数 | 说明 |
|------|------|
| `getWorldbookNames()` | 全部世界书名 |
| `getGlobalWorldbookNames()` | 全局启用列表 |
| `rebindGlobalWorldbooks(names)` | 重设全局启用 |
| `getCharWorldbookNames('current')` | 当前角色卡的 `{ primary, additional }` |
| `rebindCharWorldbooks('current', { primary, additional })` | 重绑角色卡世界书 |
| `getChatWorldbookName('current')` | 聊天绑定的世界书 |
| `rebindChatWorldbook('current', name)` | 重绑聊天世界书 |
| `getOrCreateChatWorldbook('current')` | 获取或新建聊天世界书 |

### 内容管理

| 函数 | 说明 |
|------|------|
| `getWorldbook(name)` | 获取条目数组（async） |
| `createWorldbook(name, entries?)` | 新建，存在则返回 false |
| `createOrReplaceWorldbook(name, entries?, {render})` | 建或替换 |
| `deleteWorldbook(name)` | 删除 |
| `replaceWorldbook(name, entries, {render})` | 完全替换 |
| `updateWorldbookWith(name, updater, {render})` | 函数式更新 |
| `createWorldbookEntries(name, new_entries[], {render})` | 新增条目，返回补全字段后的结果 |
| `deleteWorldbookEntries(name, predicate, {render})` | 按谓词删除 |

```js
// 给世界书加一条蓝灯条目
await createWorldbookEntries('eramgt', [{
  name: '变量列表',
  content: '---\n<status_current_variable>\n{{format_message_variable::stat_data}}\n</status_current_variable>',
  strategy: { type: 'constant' },
  position: { type: 'at_depth', role: 'system', depth: 0, order: 80 },
}]);
```

## 5. 正则 API（tavern_regex）

### `formatAsTavernRegexedString(text, source, destination, option)`

手动对文本应用酒馆正则（状态栏前端读取消息原文后再处理时常用）。

```js
const result = formatAsTavernRegexedString(
  getChatMessages(-1)[0].message,
  'ai_output', 'display', { depth: 0 }
);
```

- `source`: `'user_input' | 'ai_output' | 'slash_command' | 'world_info' | 'reasoning'`
- `destination`: `'display' | 'prompt'`

### 正则对象结构

```ts
type TavernRegex = {
  id: string;
  script_name: string;
  enabled: boolean;
  find_regex: string;
  replace_string: string;
  trim_strings: string[];
  source: { user_input: bool; ai_output: bool; slash_command: bool; world_info: bool; reasoning: bool };
  destination: { display: bool; prompt: bool };
  run_on_edit: boolean;
  min_depth: number | null;
  max_depth: number | null;
};
```

### 管理函数

| 函数 | 说明 |
|------|------|
| `isCharacterTavernRegexesEnabled()` | 角色卡局部正则是否启用 |
| `getTavernRegexes({type:'global'|'character'|'preset'})` | 获取正则（按生效顺序） |
| `replaceTavernRegexes(regexes, option)` | 完全替换（**慢**，会重载聊天） |
| `updateTavernRegexesWith(updater, option)` | 函数式更新 |

```js
await updateTavernRegexesWith(regexes => {
  regexes.forEach(r => { if (r.script_name.includes('舞台少女')) r.enabled = true; });
  return regexes;
}, { type: 'global' });
```

## 6. 生成 API（generate）

### `generate(config)` → Promise<string | GenerateToolCallResult>

使用当前预设（含预设正则/脚本）请求 AI 生成。

```js
const result = await generate({
  user_input: '你好',
  injects: [{ role: 'system', content: '思维链...', position: 'in_chat', depth: 0, should_scan: true }],
  overrides: { char_personality: '温柔' },
  max_chat_history: 50,
});
```

### `generateRaw(config)` → Promise<string | GenerateToolCallResult>

不使用预设，自定义提示词顺序。

```js
const result = await generateRaw({
  user_input: '你好',
  ordered_prompts: ['char_description', 'chat_history', 'user_input'],
});
```

### 关键配置项

| 字段 | 说明 |
|------|------|
| `preset_name` | `'in_use'`（默认）或指定预设名 |
| `generation_id` | 唯一标识，配合 stopGenerationById |
| `user_input` | 用户输入 |
| `image` | File/base64/URL 或数组 |
| `should_stream` | 流式，监听 `iframe_events.STREAM_TOKEN_RECEIVED_FULLY` |
| `should_silence` | 静默（不受停止按钮控制） |
| `overrides` | 覆盖 char_description 等提示词、chat_history |
| `injects` | 额外注入提示词 |
| `max_chat_history` | `'all'` 或数量 |
| `custom_api` | `{ proxy_preset?, apiurl?, key?, model?, source? }` |
| `tools` / `tool_choice` | 函数调用（OpenAI 格式） |
| `json_schema` | 强制结构化输出 |

### 其他

| 函数 | 说明 |
|------|------|
| `getProxyPresetNames()` | 代理预设名列表 |
| `getModelList({ apiurl, key? })` | 模型列表 |
| `stopGenerationById(id)` | 停止指定生成 |
| `stopAllGeneration()` | 停止全部 |

**MVU 场景**（请求 AI 生成并解析变量）：

```js
const old_data = Mvu.getMvuData({ type: 'message', message_id: getCurrentMessageId() });
const message = await generate({ user_input: '你好' });
const data = await Mvu.parseMessage(message, old_data);
await createChatMessages([{ role: 'assistant', message, data }]);  // 回复+变量一起建楼
```

## 7. 事件 API（event）

事件系统**跨 iframe**（共享主线程 eventSource）。iframe 销毁时监听自动卸载。

### 监听/发送函数

| 函数 | 说明 |
|------|------|
| `eventOn(type, listener)` | 注册监听；重复注册无效；返回 `{ stop }` |
| `eventMakeLast(type, listener)` | 注册并排到监听顺序最后 |
| `eventMakeFirst(type, listener)` | 注册并排到最前 |
| `eventOnce(type, listener)` | 只触发一次 |
| `eventEmit(type, ...data)` | 发送事件（可带数据），返回 Promise |
| `eventEmitAndWait(type, ...data)` | 发送并等待全部处理完 |
| `eventRemoveListener(type, listener)` | 移除指定监听 |
| `eventClearEvent(type)` | 清除本 iframe 对该事件的全部监听 |
| `eventClearListener(listener)` | 清除本 iframe 该函数的全部监听 |
| `eventClearAll()` | 清除本 iframe 全部监听 |

```js
eventOn(tavern_events.MESSAGE_RECEIVED, message_id => {
  toastr.info(`收到楼层 ${message_id}`);
});
```

### iframe 事件（`iframe_events`）

| 事件 | 回调参数 |
|------|---------|
| `MESSAGE_IFRAME_RENDER_STARTED` | `(iframe_name)` |
| `MESSAGE_IFRAME_RENDER_ENDED` | `(iframe_name)` |
| `GENERATION_STARTED` | `(generation_id)` |
| `STREAM_TOKEN_RECEIVED_FULLY` | `(full_text, generation_id)` |
| `STREAM_TOKEN_RECEIVED_INCREMENTALLY` | `(incremental_text, generation_id)` |
| `GENERATION_ENDED` | `(text, generation_id)` |

### 酒馆事件（`tavern_events`，常用节选）

| 事件 | 回调参数 | 说明 |
|------|---------|------|
| `APP_READY` | `()` | 酒馆就绪 |
| `MESSAGE_RECEIVED` | `(message_id, type)` | AI 消息完成 |
| `MESSAGE_SENT` | `(message_id)` | 用户发送 |
| `MESSAGE_UPDATED` | `(message_id)` | 消息被编辑 |
| `MESSAGE_SWIPED` | `(message_id)` | 滑动换页 |
| `MESSAGE_DELETED` | `(message_id)` | 消息删除 |
| `CHAT_CHANGED` | `(chat_file_name)` | 切换聊天 |
| `CHAT_CREATED` | `()` | 新开聊天 |
| `GENERATION_STARTED` / `GENERATION_ENDED` | `(type, option, dry_run)` / `(message_id)` | 生成开始/结束 |
| `GENERATION_AFTER_COMMANDS` | `(type, option, dry_run)` | 生成前，适合注入 |
| `CHARACTER_PAGE_LOADED` | `()` | 角色卡加载完成 |
| `CHARACTER_EDITED` | `({ detail })` | 角色卡被编辑 |
| `WORLD_INFO_ACTIVATED` | `(entries)` | 世界书条目被激活 |
| `WORLDINFO_UPDATED` | `(name, data)` | 世界书更新 |
| `USER_MESSAGE_RENDERED` / `CHARACTER_MESSAGE_RENDERED` | `(message_id)` | 楼层渲染 |

> **不建议主动 `eventEmit` 酒馆事件**（发送数据格式未知）。

## 8. 注入 API（inject）

### `injectPrompts(prompts, { once? })` → `{ uninject }`

向 AI 请求注入额外提示词（跨聊天无效，需配合 `CHAT_CHANGED` 事件）。

```ts
type InjectionPrompt = {
  id: string;
  position: 'in_chat' | 'none';   // 'none' 不发 AI，仅用于激活世界书绿灯条目
  depth: number;
  role: 'system' | 'assistant' | 'user';
  content: string;
  filter?: () => boolean;          // 条件性启用
  should_scan?: boolean;           // 加入绿灯扫描文本
};
```

```js
injectPrompts([{
  id: '激活-白娅阶段',
  content: `白娅${stage}`,
  position: 'none', depth: 0, role: 'user',
  should_scan: true,               // 关键：允许用于绿灯扫描
}]);
```

### `uninjectPrompts(ids)` → void

### iframe 内工具

|------|------|------|

| `getScriptId()` | 仅脚本 iframe | 本脚本 id |
| `getIframeName()` | 全部 | iframe 标识名 |

## 18. Mvu 接口

MVU 变量框架提供的全局接口，**使用前必须 `await waitGlobalInitialized('Mvu')`**。

| 成员 | 说明 |
