# MVU Maker

> 为 **SillyTavern 角色卡**一键增强 **MVU 变量系统** 的桌面工具（Electron）。
> 可视化编辑变量结构（Schema）→ 注入 MVU 世界书 / 正则 / 酒馆助手脚本 / 状态栏 / 角色创建卡片 → 导出**酒馆可直接导入**的 PNG / JSON 角色卡。

MVU Maker 面向"已完成的纯文字角色卡"：无需手写任何代码，在图形界面里搭好变量结构，程序自动生成 Zod 脚本、变量初始化（`[InitVar]`）、变量更新规则、输出格式、状态栏与全套正则，最后导出与 SillyTavern 完全兼容的卡片文件。

---

## 🎨 Schema 画布 —— 本工具的主打功能

> **把"变量结构设计"从写代码，变成搭积木。**

角色卡的动态状态（好感度、体力、背包、称号、NPC 关系……）在 MVU 里是一棵叫 `stat_data` 的变量树。传统做法是手写一长串 Zod 代码——类型、默认值、范围钳制、字段说明全挤在一坨文本里，改一个字段就要翻代码、数括号，AI 生成的 schema 一多就无从维护。

**Schema 画布把这件事彻底可视化**：

- **画布即 Schema**：每个节点就是一个变量字段，拖拽连线决定嵌套结构，所见即所得
- **零代码**：类型、默认值、数值范围、枚举选项、字段说明全部在右侧检查器里点选填写，`z.object(...)`、`.prefault()`、`.transform(v => _.clamp(...))` 这类写法由程序自动生成
- **双向转换**：画布 ↔ Zod 代码随时互转——可以从任意 MVU 卡片的 Zod 脚本一键反推成画布继续编辑，也可以把画布导出成代码粘贴到任何地方
- **一套结构，全家受益**：画布定稿后，MVU 全家桶自动跟上——
  - `[InitVar]` 变量初始化条目：按结构生成默认空值（无需 LLM）
  - Zod 脚本：一键导入为卡内酒馆助手脚本（`registerMvuSchema`）
  - 变量更新规则 / 输出格式：字段路径与结构严格对齐
  - 校验：initvar YAML 用真实 Schema 解析验证

> 通俗地说：以前搭变量结构是"写代码"，用 Schema 画布是"画结构图"。画完，代码和配套设定自动就位。

## ✨ 功能特性

### Schema 变量结构画布
- 可视化搭建 `stat_data` 变量树：`string / number / boolean / enum / object / record / union` 七种类型
- 支持默认值（`prefault`）、数值钳制（`clamp`）、字段说明（`describe`）等 Zod 4 能力
- 画布 ↔ Zod 代码**双向转换**：可从任意 MVU 角色卡的 Zod 脚本反推画布，也可直接粘贴代码生成画布

### MVU 世界书管理
- 四大提示词条目一站式管理：
  | 条目 | 说明 |
  |------|------|
  | `[InitVar]请勿打开` | 变量初始化（**禁用**状态，MVU 引擎读取），注入时按 Schema **自动生成默认空值**，无需 LLM |
  | `变量列表` | 实时变量快照（蓝灯 @D0） |
  | `[mvu_update]变量更新规则` | 每个变量的更新触发条件 |
  | `[mvu_update]变量输出格式` | 要求 AI 以 JSON Patch 输出更新指令 |
- 条目位置自动对齐官方标准（`atDepth=4` + depth + `order=200`），导入酒馆不会错乱

### 正则脚本
- 变量更新五件套：隐藏 / 更新中 / 美化 / 隐藏状态栏 / 状态栏界面
- 内置正则测试沙盒：用示例文本实时预览替换结果
- **美化正则产物全部内联样式**（无 `<style>` 标签，酒馆沙盒 iframe 兼容）

### 酒馆助手脚本
- 脚本文本管理：查看、编辑、启停 MVU / Zod 等角色脚本
- Zod 脚本内容随画布自动生成（`registerMvuSchema`）

### 状态栏 & 角色创建卡片
- 状态栏：纯文本（宏替换）或 HTML 界面，内置沙盒 iframe 实时预览
- 角色创建卡片：开局捏人界面（占位符 + 两条正则），多步向导式
- 开场白管理：多条开场白 + 各自的 `initvar override`

### LLM 辅助（可选）
- 多服务商配置（OpenAI 兼容，任意 baseURL + apiKey + model）
- 各页面内置 AI 面板：Schema 设计、世界书、更新规则、状态栏、创建卡片、变量更新美化、开场白
- 所有任务提示词可在「LLM 提示词」页查看/编辑/导入导出；LLM 结构化输出有容错解析（代码块、解释文字、无效转义均能正确处理）

### 导出（酒馆兼容性保证）
- **PNG 导出保留原头像**：只替换 chara 数据块，像素原样字节拷贝
- chara / ccv3 以 **base64** 写入（与 SillyTavern `character-card-parser` 完全一致）
- `character_book.entries` 为**数组**（ST `convertCharacterBook` 要求）
- `tavern_helper.scripts` 为**数组**（新版酒馆助手 JS-Slash-Runner 要求，Record 会被静默丢弃）
- 导出后立即用**酒馆同款解析逻辑自检**，解析失败会明确警告
- 校验失败不阻止导出；默认文件名带时间戳，绝不覆盖源卡

### 会话持久化
- 项目自动保存（800ms 防抖），重启应用自动恢复上次工作现场

## 📖 使用流程

1. **打开角色卡**：导入 PNG / JSON 卡片（自动识别 MVU 特征）
2. **搭建 Schema**（Schema 页）：画布拖拽添加变量字段，或粘贴现有 Zod 代码反推
3. **编写 MVU 世界书**（MVU 世界书页）：编辑更新规则 / 输出格式，点「注入到世界书」——`[InitVar]` 条目自动按 Schema 生成
4. **注入组件**：状态栏 / 创建卡片 / 开场白（按需）
5. **导出**（导出页）：选 PNG 或 JSON → 保存 → 直接导入 SillyTavern

## 📐 Schema 画布 · 操作手册

### 基本概念

| 概念 | 说明 |
|------|------|
| **节点** | 画布上每一个方块/圆 = 一个变量字段（`stat_data` 里的一个键） |
| **容器** | `object / record / union` 三种类型的节点是"容器"，可以拥有子字段 |
| **嵌套** | 把字段拖到容器的右侧连接线，该字段就变成容器的子成员（可无限层级） |
| **游离字段** | 不属于任何容器的顶层字段（直属于根节点） |
| **根节点** | 画布中心的主节点，所有顶层字段从它长出 |

### 快速上手（5 步）

1. **新建字段**：在画布**空白处右键**，弹出环形菜单，点选类型（文本 / 数值 / 布尔 / 枚举 / 记录 / 对象 / 联合）→ 在鼠标位置生成一个游离字段
2. **命名与设置**：点选字段，右侧**字段检查器**出现——填名称，按类型配置默认值 / 范围 / 枚举项 / 描述
3. **搭结构**：把字段**拖到容器（object/record）节点的右侧连接线**上，松手即成为其子成员；想放回顶层就拖到根节点
4. **微调**：选中成员**右键**可复制（整个子树）/ 脱离 / 删除；`Ctrl+Z` / `Ctrl+Y` 撤销重做（20 步）
5. **定稿**：点「⬇ 一键导入为 Zod 脚本」写入卡内酒馆助手脚本，或点「复制 Schema 代码」带走

### 操作速查

| 操作 | 方式 |
|------|------|
| 新建游离字段 | **右键画布空白** → 环形菜单选类型 |
| 嵌套为子成员 | 拖拽字段到容器节点**右侧连接线**上松手（object/record/union 均可） |
| 编辑字段属性 | 点选节点 → 右侧**字段检查器**（名称 / 类型 / 默认值 / 范围 / 枚举 / 描述） |
| 复制子树 | 选中成员 → **右键** → ⧉ 复制（或 `Ctrl+C`），含全部子孙、保留内部父子关系 |
| 粘贴 | `Ctrl+V`（粘贴到最近鼠标位置，作为游离结构）或 Shift+右键 → 粘贴 |
| 删除 | 选中成员 → **右键** → 🗑 删除（连同整个子树） |
| 脱离容器 | 选中成员 → **右键** → ⤴ 脱离（从容器移出为游离字段） |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y`（最多 20 步历史） |
| 全局菜单 | **Shift+右键**（粘贴 / 撤销 / 重做） |
| 从卡内脚本加载 | 工具栏下拉选择卡内的 Zod 脚本 → 自动反推为画布（可继续编辑） |
| 一键导入为 Zod 脚本 | 工具栏「⬇ 一键导入为 Zod 脚本」→ 写入/更新卡内酒馆助手脚本 |
| 复制 Schema 代码 | 代码面板「⧉ 复制」或「🔄 刷新」查看最新生成的 zod 代码 |
| 视图 | 「◎ 定位主 Schema」回到根节点；「⛶ 适配」缩放到全览 |

### 七种字段类型详解

| 类型 | 节点颜色 | 用途 | 检查器可设 |
|------|---------|------|-----------|
| **文本** `string` | 🔵 | 名字、状态、描述等任意字符串 | 默认值 `prefault` |
| **数值** `number` | 🟢 | HP、好感度等数字 | 是否整数、范围钳制 `clamp`（下限/上限）、默认值 |
| **布尔** `boolean` | 🟡 | 开关型状态（觉醒、中毒…） | 默认值 |
| **枚举** `enum` | 🟣 | 固定取值（属性：火/水/雷） | 枚举值列表（换行分隔）、默认值 |
| **记录** `record` | 🟠 | **动态键**集合（背包、称号、NPC 列表——键由剧情产生） | value 结构通过拖拽子字段定义 |
| **对象** `object` | 🟠 | 固定字段的分组（人物档案、装备栏） | 子字段通过拖拽定义 |
| **联合** `union` | 🔵 | 字段值可为多种类型之一（`z.union([string, number])`） | 每个子节点 = 一种可选类型 |

> **record vs object**：`record` 的键是**动态**的（物品名、NPC 名由剧情产生，AI 可自由增删）；`object` 的键是**固定**的（字段写死在 schema 里）。记不住就记：*背包、称号表用 record，人物档案、状态栏用 object*。

### 画布 → MVU 全家桶

画布是**唯一事实来源**，一切从它自动生成：

```
Schema 画布
 ├─► Zod 脚本（一键导入）       → 变量结构与约束注册进酒馆
 ├─► [InitVar] 初始变量（注入时）→ 全字段默认空值，无需 LLM
 ├─► 变量更新规则 / 输出格式    → 路径与结构严格对齐，AI 不会改错路径
 └─► initvar 校验               → 用真实 Schema 解析验证 YAML
```

改动结构后记得：点「⬇ 一键导入为 Zod 脚本」更新脚本 → MVU 世界书页点「注入到世界书」刷新 `[InitVar]` → 导出。

## 🔧 关键兼容性设计（踩坑记录）

| 问题 | 原因 | 本工具的解法 |
|------|------|-------------|
| 导入报 `Unexpected token '�'` | chara 内容需 **base64**，写裸 JSON 会被 ST 解成乱码 | 导出时 chara/ccv3 一律 base64（与 ST `write` 一致） |
| `characterBook.entries.forEach is not a function` | `entries` 必须为**数组**（spec） | 全程数组；读取端兼容对象形式自动归一化 |
| 卡里有脚本但酒馆助手看不到 | 新版酒馆助手要求 `tavern_helper.scripts` 为**数组**（元素含 `name`） | 导出转数组（含 `type/enabled/name/…/export_with`） |
| MVU 条目位置错乱 | `extensions.position` 6 是"示例消息之后"，`@D` 应为 **4**（atDepth） | 模板 + 注入 + 导出三重规范化（atDepth=4 + depth + order=200） |
| 美化正则样式丢失 | 沙盒 iframe 剥离 `<style>` 标签 | 全部改内联 `style` 属性，提示词同步约束 |

## 🔒 隐私说明

- **API Key 只存用户数据目录**（`%APPDATA%/mvu-maker/`），不在项目目录、不入 Git 仓库、不打包进产物
- 源码中的 `apiKey` 均为空默认值，无任何硬编码密钥
- LLM 请求日志写入用户目录 `logs/llm.log`，仅本机可见
- 会话项目自动保存到用户目录，不会随仓库/安装包分发
